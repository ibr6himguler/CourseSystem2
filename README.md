# Course Management System

A desktop application developed in Java for managing course and student information through a graphical interface.

## Features
- Manage course and student records
- Simple and user-friendly interface
- Desktop application built with Java Swing
- Database connectivity using JDBC

## Technologies
- Java
- Java Swing
- JDBC

## Purpose
This project was developed to practice object-oriented programming, desktop application development, and working with database-connected applications.
